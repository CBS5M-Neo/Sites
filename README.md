# Neo Sites — автоматическая система создания сайтов

**Neo** — подкомпания [CBS5M](https://github.com/CBS5M-Neo), создающая **статичные сайты
с помощью ИИ** (модели GLM-5.3-flash, Hy3, Qwen3.8-Flash, Mimo-v2.5 внутри DeepSeek Harness).

Этот репозиторий — одновременно **каталог всех сайтов** и **конвейер их автоматической
генерации**: заявка → проверка и улучшение промпта → генерация ИИ → публикация.

🔗 Лендинг: <https://cbs5m-neo.github.io/>
🔗 Каталог сайтов: <https://cbs5m-neo.github.io/Sites/>

---

## Как заказать сайт

1. Откройте [**New issue → 🌐 Заказ сайта**](https://github.com/CBS5M-Neo/Sites/issues/new?template=new-site.yml)
2. Заполните название и описание своими словами, при желании выберите модель ИИ
3. Автоматика Neo: проверит заявку, **улучшит промпт**, проверит выбранную модель
   (при исчерпанном лимите возьмёт другую), сгенерирует сайт, создаст папку
   `<имя-сайта>/` в этом репозитории и опубликует сайт
4. Готовый сайт появится по адресу
   `https://cbs5m-neo.github.io/Sites/<имя-сайта>/`, а ссылка придёт в issue

### Модели ИИ

| Модель | В заявке / Actions | Особенности |
|---|---|---|
| `glm-5.3-flash` | **GLM-5.3-flash (умолчание)** | лучшая по качеству/скорости |
| `hy3` | Hy3 | альтернатива |
| `qwen3.8-flash` | Qwen3.8-Flash | альтернатива |
| `mimo-v2.5` | Mimo-v2.5 | альтернатива |

Перед каждым этапом pipeline **пробует модель коротким запросом**; если она не
отвечает (лимит исчерпан, таймаут, ошибка API) — автоматически перебирает
остальные и берёт первую рабочую. Отчёт о том, какая модель реально генерировала
сайт, сохраняется в `sites.json` и виден в каталоге и в комментарии issue.

### Правки

- В стоимость сайта входят **8 правок** — оформляются через
  [шаблон «🛠️ Правка сайта»](https://github.com/CBS5M-Neo/Sites/issues/new?template=edit-site.yml)
- Каждая правка сверх восьми — **10 ₽** (учёт ведётся в `sites.json`)

### Если на сайт никто не приходит

Раз в неделю автоматика проверяет посещаемость:

| Опция при заказе | Неделя без посетителей |
|---|---|
| **Включена** | списывается **20 ₽** (при долге сайт отключается) |
| **Выключена** | списаний нет, но сайт **автоматически выключается** |

Включить сайт обратно можно бесплатно:
[шаблон «🔁 Включить сайт»](https://github.com/CBS5M-Neo/Sites/issues/new?template=reactivate-site.yml).

## Как устроен конвейер

```
issue «Заказ сайта» (ярлык «новый-сайт»)
        │
        ▼
┌─────────────────────────────┐
│ pipeline/enhance-prompt.js  │  Этап 1. Проверка модели и заявки, улучшение промпта.
│ (GLM/Hy3/Qwen/Mimo, JSON)   │  Отклоняет мусор, дополняет детали, фиксирует стиль.
└─────────────┬───────────────┘
              ▼
┌─────────────────────────────┐
│ pipeline/generate-site.js   │  Этап 2. DeepSeek Harness headless: агент создаёт
│ (агент с доступом к файлам) │  папку <slug>/ и пишет готовый index.html.
└─────────────┬───────────────┘
              ▼
┌─────────────────────────────┐
│ pipeline/new-site.js        │  Этап 3. Перенос в репозиторий, запись в sites.json,
│ (коммит, пуш, комментарий)  │  коммит, пуш, ссылка в issue.
└─────────────────────────────┘
```

**Ручной запуск:** Actions → «Neo · Новый сайт» → Run workflow → ввести описание.

### Структура репозитория

```
Sites/
├── <имя-сайта>/index.html     # сайты клиентов (папка = имя сайта)
├── index.html                 # каталог всех сайтов
├── sites.json                 # реестр: статусы, балансы, правки, посещаемость
├── pipeline/                  # конвейер (Node.js, без зависимостей)
│   ├── lib/common.js          # общие утилиты: dsh-вызовы, git, реестр, slug
│   ├── enhance-prompt.js      # этап 1 — проверка и улучшение промпта
│   ├── generate-site.js       # этап 2 — генерация сайта ИИ-агентом
│   ├── apply-edit.js          # правки существующего сайта + учёт 10 ₽
│   ├── new-site.js            # оркестратор нового сайта
│   ├── weekly-check.js        # еженедельная проверка посещаемости
│   ├── reactivate.js          # повторное включение сайта
│   ├── health-check.js        # CI-проверка целостности
│   └── dsh-settings.yaml      # 4 модели для DeepSeek Harness (провайдер bai)
├── docs/SYSTEM.md             # подробное описание системы
└── .github/workflows/         # new-site, edit-site, weekly-check, reactivate, pages, health
```

### Workflows

| Workflow | Триггер | Что делает |
|---|---|---|
| `new-site.yml` | issue «новый-сайт», вручную | полный цикл создания сайта |
| `edit-site.yml` | issue «правка», вручную | правка сайта + учёт оплат |
| `weekly-check.yml` | понедельник 06:00 UTC, вручную | посещаемость, списания, отключения |
| `reactivate-site.yml` | issue «включить-сайт», вручную | возврат сайта в строй |
| `pages.yml` | push в main | публикация каталога на GitHub Pages |
| `health.yml` | push в main | проверка sites.json и файлов сайтов |

## Настройка (для владельца)

1. **GitHub Pages** — включается автоматически при первом запуске workflow `pages.yml`
   (push в `main`); адрес каталога: <https://cbs5m-neo.github.io/Sites/>.
2. **Секрет `BAI_API_KEY`** — Settings → Secrets and variables → Actions → New secret:
   ключ провайдера B.AI для моделей GLM-5.3-flash / Hy3 / Qwen3.8-Flash / Mimo-v2.5.
3. (Необязательно) **Счётчик посещений** — см. [docs/SYSTEM.md](docs/SYSTEM.md),
   раздел «Подсчёт посещений», и секрет `VISITS_CSV_URL`.
4. Локальный запуск без CI: `node pipeline/new-site.js --request-file request.txt --workdir .`
   (нужен установленный `dsh` и настроенный патч, как в `setup-dsh.sh`).
